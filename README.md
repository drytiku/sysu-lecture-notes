# 中山大学物理学院 · 期末冲刺讲义（公网版）

面向中山大学物理学院大一学生的四门课学习讲义：

- **高等数学**（北大版《高等数学》）
- **力学**（赵凯华、罗蔚茵《新概念物理教程·力学》第三版）
- **热学**（赵凯华、罗蔚茵《新概念物理教程·热学》第三版）
- **线性代数**（丘维生《高等代数》第四版）

## 内容特点

- 每章以历史故事引入，每节设"引入"（思想渊源）与"推导"（原理的完整推演）
- 每节配套约十道练习，章末二十道综合题，答案统一附于书末并逐题标注考点与方法
- 收录中山大学历年期末真题（标注年份与出处）及其它高校流传真题
- 知识点之间标注跨章、跨科联系（高数 ↔ 力学 ↔ 热学 ↔ 线代）

## 使用方式

- **在线阅读**：点击上方文件列表中的 `index.html` 即可开始（浏览器打开，公式由 MathJax 渲染，需联网）
- **离线打印**：进入 `Word版` 文件夹下载对应科目的 `.docx`，公式为原生 Word 公式，可直接打印
